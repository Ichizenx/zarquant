# Zarquant · زارکوانت

Static market dashboard for the Tehran Stock Exchange (TSETMC): a TradingView-style
dark interface with a smooth candlestick chart in the centre and the watchlist on the
right. No backend, no bundler — plain HTML, CSS and JavaScript served by GitHub Pages.

- **Live site:** https://ichizenx.github.io/zarquant/
- **Access password:** `e19m_1iLL` (the page itself is encrypted with StatiCrypt)
- **Data:** `data.json`, refreshed by a scheduled GitHub Action

## Layout

```
top bar   brand · daily/weekly/monthly · sync time · refresh
┌───────────────────────────────────────────┬──────────────────┐
│ symbol · price · day change                │ watchlist        │
│ OHLC legend · candles/line/area · tools    │ search           │
│ candlestick chart + volume pane            │ collapsible      │
│ footer stats (last, close, change, …)      │ groups + rows    │
├───────────────────────────────────────────┤                  │
│ market pulse strip (count, value, movers)  │                  │
└───────────────────────────────────────────┴──────────────────┘
```

## Files

| Path | Role |
| --- | --- |
| `index.src.html` | **Plain page template — edit this one.** Encrypted into `index.html` by CI. |
| `index.html` | Password-gated build artifact generated by StatiCrypt (never edit by hand). |
| `style.css` | Flat dark theme, grid layout, responsive drawer for the watchlist. |
| `chart.js` | Canvas candlestick engine: crosshair, zoom, pan, volume, price/time axes. |
| `script.js` | Data loading, watchlist, search, selection, history cache, chrome. |
| `fetch_data.py` | TSETMC → `data.json` (standard library only). |
| `data.json` | Generated dataset (~480 KB): market watch + seeded daily candles. |
| `.github/workflows/update.yml` | Daily refresh + StatiCrypt encryption + commit. |
| `PROJECT_NOTES.md` | Architecture, data schema and handover notes. |

## Local preview

```powershell
# from the repository root — fetch() needs HTTP, file:// will not work
python -m http.server 8765 --bind 127.0.0.1
# then open http://127.0.0.1:8765/index.src.html
```

`index.src.html` is the plain template, so it previews without the password gate;
`index.html` is the encrypted copy that GitHub Pages serves.

## Refreshing data

```powershell
python fetch_data.py -o data.json            # 150 candles, 8 seeds per group
python fetch_data.py --history 0             # market watch only
python fetch_data.py --insecure              # networks with a TLS-inspecting proxy
```

TSETMC geo-blocks many non-Iranian networks, so the scheduled job may fail at the
fetch step; the site keeps serving the last committed `data.json` and the encrypted
page is still rebuilt. See `PROJECT_NOTES.md` for the details.
